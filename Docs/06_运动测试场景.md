# 06 运动模块测试场景（A 方案）

场景：`Assets/Scenes/Locomotion_TestLab.unity`

用途：在同一个场景里可视调参、观察运动模块效果。它不替代 PlayMode 自动测试；自动回归仍由 `MNAC.Tests.TPhysics.PlayMode` 负责。

## 快速开始

1. 打开 `Assets/Scenes/Locomotion_TestLab.unity`
2. 点 Play
3. 让 Game View 获得焦点
4. `WASD` 移动，`Space` 跳跃，`Shift` 冲刺，`Ctrl` 急停
5. 数字键 `1`–`8` 切换模块预设；`R` 重置

## 按键

| 按键 | 作用 |
|---|---|
| `WASD` | 世界轴移动（W = +Z） |
| `Space` | 跳跃 |
| `Left Shift` / `Right Shift` | 冲刺 |
| `Left Ctrl` / `Right Ctrl` | 急停 |
| `1`–`8` | 切换预设 |
| `R` | 重置玩家、速度、地面检测和统计 |
| `C` | 切换相机：跟随 / 侧视 / 顶视 |
| `Q` | 循环切换转向目标 |
| `E` | 清除目标，回退到鼠标朝向 |
| `F1` | 隐藏 / 显示 HUD |

数字键使用主键盘 `Alpha1`–`Alpha8`，小键盘不响应。

## 预设

| 键 | 预设 | 模块 |
|---|---|---|
| 1 | Move | VerticalPostureEvaluator + HorizontalLocomotion |
| 2 | Dash | Move + BoostingLocomotion（Shift 触发） |
| 3 | Jump | Move + JumpLocomotion（Space 触发） |
| 4 | Rotate | Move + RotationByMouseOrTargetLocomotion |
| 5 | Stop | Move + StopLocomotion（松开 WASD 自动急停） |
| 6 | Drag | Move + MutativeDrag |
| 7 | Posture | Move + Jump，只保留姿态观察和跳跃 |
| 8 | Full | 全部模块，压力测试 |

切换预设或按 `R` 会重建模块实例并回到出生点，避免 Timeline、Drag、Dash 状态残留。

## 场地

- 30m 直道，每 5m 一个距离标记
- 15° / 30° / 45° / 60° 坡道
- 0.3 / 0.6 / 0.9m 台阶、墙、天花板
- 跳跃台 + 0.5m 间隔高度尺
- 4 个转向目标（N/E/S/W）
- 急停区、阻力区、零摩擦区
- 普通摩擦地面和零摩擦地面分开，便于隔离“模块驱动”和“物理摩擦”的影响

## HUD

左上角显示：

- 当前预设、相机模式
- 合速度 / 水平速度 / 竖直速度
- 是否接地、地面法线角度
- `VerticalPosture`、当前 Rigidbody drag
- 距离、运行时间
- 峰值水平速度、最高点
- 10m / 20m 用时、最近一次急停距离
- 当前模块及启用状态
- 当前转向目标

HUD 按屏幕高度缩放；Game View 分辨率过低时字号会变小。

## 代码

- `Assets/Scripts/Demo/TPhysics/Locomotion/LocomotionTestDriver.cs`
  - 模块装配、预设切换、输入映射、指标统计
  - `[DefaultExecutionOrder(-100)]`，在 `LocomotionVisualRunner.FixedUpdate` 之前写入模块
- `Assets/Scripts/Demo/TPhysics/Locomotion/LocomotionTestHud.cs`
  - IMGUI HUD，只读驱动数据
- `Assets/Scripts/Demo/TPhysics/Locomotion/LocomotionTestCamera.cs`
  - 跟随 / 侧视 / 顶视相机
- `Assets/Scripts/Demo/TPhysics/Locomotion/TransformPositionTarget.cs`
  - 把场景 Transform 适配成 `IPositionTarget`
- `Assets/Scripts/Demo/TPhysics/MNAC.Demo.TPhysics.asmdef`
  - 新增 `MNAC.Interaction` 引用

核心运动模块没有修改。

## 注意

- `Stop` 预设的急停逻辑是“松开方向键就启用 StopLocomotion”，按 `Ctrl` 也可以手动急停。
- `Drag` 预设会在 1.5s 内把 Rigidbody drag 从 0.2 过渡到 3；重置会把 drag 清零。
- `Rotate` 预设默认朝鼠标；按 `Q` 后才切到场景目标。
- 测试场景是 Demo 层，不应把玩法逻辑反向塞进 `MNAC.TPhysics`。
