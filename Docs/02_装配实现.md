## 二、新 API 用法
```csharp
var core = new LocomotionCore(world, rbody, groundDetector);   // 或 new LocomotionCore(context)
core.SetModules(new ILocomotionModule[] {
    new VerticalPostureEvaluator(60),   // Priority 决定执行顺序（这里为默认 0，同优先级保持列表顺序）
    new HorizontalLocomotion(6f, 12f),
    new JumpLocomotion(1.2f),
});
core.EnableModule(jump);   // 运行时启停仍可用
core.AddModule(dash);      // 单个插入：按 Priority 二分定位；null/重复忽略
jump.Priority = -1;        // 运行时改优先级：赋值即重排（无需等 Update）
core.Update();
```

## 四、遗留 / 给测试线提示
1. 运行时**按 Priority 升序执行**（二分插入），同优先级保持面板列表顺序。VerticalPostureEvaluator 需最先读取姿态时，把它的 Priority 设为更小值（或保持同优先级并排最前）。运行时可随时修改 `Priority`，**赋值瞬间重排**；但在 `Update` 迭代期间修改会被拒绝并告警（避免迭代中扰动列表）。新增模块用 `AddModule` 即可（或整体 `SetModules`）。
2. 反序列化后模块 `Enabled` 走基类序列化字段；`VerticalPostureEvaluator` 需在面板勾选启用（其无参默认禁用）。
3. `RotationByMouseOrTargetLocomotion.Target` 为 `[NonSerialized]`：面板当前无法持久化目标引用，需运行时赋值（无现成 `[Serializable] IPositionTarget` 实现）。
4. 接口变更点：旧 `AddModule/AddModule_InsertByPriority/RemoveModule` 已删，统一 `SetModules`。`Modules` 顺序语义为"按 Priority 升序，同优先级按装配顺序"。
