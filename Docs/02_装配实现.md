## 二、新 API 用法
```csharp
var core = new LocomotionCore(world, rbody, groundDetector);   // 或 new LocomotionCore(context)
core.SetModules(new ILocomotionModule[] {
    new VerticalPostureEvaluator(60),   // 顺序 = 执行顺序
    new HorizontalLocomotion(6f, 12f),
    new JumpLocomotion(1.2f),
});
core.EnableModule(jump);   // 运行时启停仍可用
core.Update();
```

## 四、遗留 / 给测试线提示
1. 运行时**不再自动按 Priority 排序**；执行顺序 = 面板顺序。VerticalPostureEvaluator 需最先读取姿态时在面板里排最前。
2. 反序列化后模块 `Enabled` 走基类序列化字段；`VerticalPostureEvaluator` 需在面板勾选启用（其无参默认禁用）。
3. `RotationByMouseOrTargetLocomotion.Target` 为 `[NonSerialized]`：面板当前无法持久化目标引用，需运行时赋值（无现成 `[Serializable] IPositionTarget` 实现）。
4. 接口变更点：旧 `AddModule/AddModule_InsertByPriority/RemoveModule` 已删，统一 `SetModules`。旧的 `Modules` 顺序断言语义已从"按 Priority 升序"变为"按装配顺序"。
