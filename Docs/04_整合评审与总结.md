## 三、评审要点（自检）
- **引用干净**：grep 确认 `AddModule / AddModule_InsertByPriority / RemoveModule / FindIndexByPriority / ModuleState / _modules` 在 Assets 下零残留；`ArrayExtensions` 已不再被 TPhysics 消费。
- **基石库纯度**：`MNAC.TPhysics` 仍无 MonoBehaviour/无 Editor 依赖；Runner 与 Editor 均落在独立的 `MNAC.Demo*` 消费方程序集。
- **行为保留**：模块只做序列化加法，既有参数化构造与 setter 全保留；`Wrapper` stepNum 生命周期状态机原样保留。
- **语义变更（有意为之）**：执行顺序=装配顺序；`Priority` 变为纯元数据（面板排序用）。原唯一好路径 `AddModule_InsertByPriority` 的自动排序被面板手排取代。

## 五、遗留 / 建议下一步
1. **面板需人工目检**：无 Inspector 截图工具；请按 `Docs/03` 第六节新建场景 + Runner 手动验证增删/排序/启停/参数，Play 后看运动是否按清单执行。
2. `RotationByMouseOrTargetLocomotion.Target`（IPositionTarget）无现成可序列化实现 → 面板无法持久化目标引用（运行时赋值）。可后续补一个 `[Serializable]`/Mono 的目标实现。
3. `TPhysics.Context.SynchronizeFromRigidbody` 不刷新 `CurrentSpeed`（-1 直到 setter）——既有语义，测试已注释；如需要可单独修复。
4. 更多模块数值边界与 Runner 接线冒烟可增量补 PlayMode（用例框架见 `01_需求分析` D 节）。
5. 本轮大量改动**尚未 git 提交**（含 Docs/、Demo/、测试、迁移），是否提交由你决定（默认不主动 commit）。
